# Sistema de Gerenciamento de Tarefas Ágil

## Objetivo
Sistema simples de gerenciamento de tarefas utilizando metodologia ágil (Kanban).

## Tecnologias
Python, Flask, Pytest, GitHub Actions

## Mudança de Escopo
Adição do campo prioridade para tarefas.

## Execução
pip install -r requirements.txt
python src/app.py
